// Internal Tool · Django · PostgreSQL

Transport
Management
System

A CMS built for the realities of transport and logistics. Manage contractors, track orders, handle carriers — all in one system built from the ground up. No off-the-shelf software that almost fits. Something that actually does.

// 01
Contractor Management

Full contractor database with contact management, document tracking and compliance status. Know exactly who you're working with and where every agreement stands.

// 02
Order Tracking

Create, assign and track transport orders through their full lifecycle. Status updates, carrier assignment, delivery confirmation — one view, no spreadsheets.

// 03
Carrier Network

Carrier profiles, route history, rating system. Build a network of trusted carriers and match orders intelligently based on availability and past performance.

// 04
Document Management

CMR documents, invoices, contracts — attached directly to orders and contractors. Everything accessible, nothing lost in email threads.

// Tech Stack
Python Django PostgreSQL Docker Nginx Linux / VPS

Built because no existing tool fit the actual workflow. The logic is in the domain — not in the framework.
